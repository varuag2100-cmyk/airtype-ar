AirType AR

Camera-based marker anchoring experiment

World anchoring for phones without WebXR AR

Ready. This mode tracks a visual marker instead of requiring ARCore support.
How this works: the 3D keyboard is attached to a printed Hiro marker or the same marker shown on a second screen. The camera tracks that marker, so the keyboard stays aligned with it while it remains visible. This is marker-based AR, not ARCore plane detection; it does not anchor to an arbitrary table without a marker.

Live AR view

Place the complete Hiro marker flat on a table. Make it at least 12 cm wide, keep the full white margin visible, fill about 25–60% of the camera view, and avoid glare or blur. Use the rear camera. The marker must be the exact Hiro pattern, not a similar-looking square.

Open Hiro marker image on another device / print it

Text tools

The on-screen touch keyboard is not included. The phone's standard keyboard may appear when you tap the text box.

Compatibility

Works through camera-based visual marker tracking, so it does not require immersive WebXR or ARCore. It does require HTTPS, camera permission, WebGL, internet access to load AR.js/A-Frame, and a visible Hiro marker. Performance varies by browser and lighting.
