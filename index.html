1. Start spatial AR

Checking AR support…

Tap Start AR. If this browser/device cannot run immersive AR, AirType will open the camera preview and explain what is unsupported. True room anchoring requires WebXR + ARCore support.

Compatibility note: This is a WebXR demo, not a finished hand-tracking keyboard. A supported browser/device is required. Browsers do not expose reliable fingertip-to-key contact across Android devices, so this page does not claim physical finger typing. If WebXR is unavailable, use voice typing or the text field.

2. Camera preview fallback

Camera preview · AR placement requires WebXR

This is a camera preview only. It does not create world-anchored AR by itself.

3. Type here

The on-screen touch keyboard has been removed. Use your phone’s normal text-entry keyboard in this field, or use Voice typing below.

Optional device permissions

Location is not needed for room-scale tracking; GPS cannot anchor a keyboard inside a room. Microphone access is requested only when you tap voice typing. Camera access is requested when you enable camera or start AR.
